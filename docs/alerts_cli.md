# Nessi Alerts CLI

The Nessi Alerts CLI provides a comprehensive interface for monitoring, managing, and responding to alerts generated by the Nessi data quality monitoring system.

## Features

### Alert Monitoring
- View all active alerts via CLI commands
- Filtering by severity, status, and source
- Detailed alert information including timestamps, descriptions, and related metrics

### Alert Management
- Acknowledge alerts to indicate they are being addressed
- Resolve alerts once the underlying issue has been fixed
- Silence alerts for a specified duration to temporarily suppress notifications

### Alert Rules
- Create and manage alert rules based on metrics and thresholds
- Enable/disable rules as needed
- Delete rules that are no longer relevant

## Using the Alerts CLI

### Viewing Alerts
Use the following command to view all alerts in the system:

```bash
nessi alerts list [--severity=<level>] [--status=<status>] [--source=<source>]
```

Each alert entry shows:
- Alert name and description
- Severity (critical, warning, info)
- Current status (active, acknowledged, resolved, silenced)
- Source of the alert
- Timestamp when the alert was created

### Alert Actions
For each alert, you can:

1. **Acknowledge**: Indicate you are aware of the alert and working on it
   ```bash
   nessi alerts acknowledge <alert_id> [--comment="Working on this issue"]
   ```

2. **Resolve**: Mark the alert as resolved when the underlying issue has been fixed
   ```bash
   nessi alerts resolve <alert_id> [--comment="Fixed by updating table schema"]
   ```

3. **Silence**: Temporarily suppress notifications for this alert
   ```bash
   nessi alerts silence <alert_id> --duration=2h [--reason="Maintenance in progress"]
   ```
   - Specify the duration (in hours) for which the alert should be silenced
   - Provide a reason for silencing the alert

### Alert Rules Management
Manage alert rules with the following commands:

1. **List Rules**:
   ```bash
   nessi alerts rules list
   ```

2. **Create Rule**:
   ```bash
   nessi alerts rules create --metric="table_freshness" --table="my_table" --threshold=24 --operator=">" --severity="warning"
   ```
   - Specify the metric to monitor
   - Set the threshold value
   - Choose the comparison operator (>, <, =, etc.)
   - Set the severity level

3. **Update Rule**:
   ```bash
   nessi alerts rules update <rule_id> --threshold=12 --severity="critical"
   ```

4. **Enable/Disable Rule**:
   ```bash
   nessi alerts rules enable <rule_id>
   nessi alerts rules disable <rule_id>
   ```

5. **Delete Rule**:
   ```bash
   nessi alerts rules delete <rule_id>
   ```

## Alert Notifications

Nessi can send alert notifications through various channels:

### Email Notifications
Configure email notifications in your Nessi configuration file:

```yaml
alerts:
  notifications:
    email:
      enabled: true
      smtp_server: "smtp.example.com"
      smtp_port: 587
      username: "alerts@example.com"
      password: "${NESSI_SMTP_PASSWORD}"
      from: "nessi-alerts@example.com"
      recipients:
        - "data-team@example.com"
```

### Webhook Notifications
Configure webhook notifications to integrate with other systems:

```yaml
alerts:
  notifications:
    webhook:
      enabled: true
      url: "https://hooks.example.com/services/T00000000/B00000000/XXXXXXXXXXXXXXXXXXXXXXXX"
      headers:
        Content-Type: "application/json"
        Authorization: "Bearer ${NESSI_WEBHOOK_TOKEN}"
```

## Alert Reports

Generate comprehensive reports of alerts for documentation and analysis:

```bash
nessi alerts report --from="2025-05-01" --to="2025-05-20" --format=pdf --output="alerts-report.pdf"
```

Supported formats include:
- HTML (interactive report viewable in a browser)
- PDF (printable document)
- JSON (machine-readable format for integration)
- CSV (tabular data for spreadsheet analysis)
