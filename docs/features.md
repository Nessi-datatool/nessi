## Getting Started

1. **Installation**
   ```bash
   git clone https://github.com/nessi-dev/nessi.git
   cd nessi
   docker-compose up -d
   ```

2. **Access Services**
   - Backend API: https://localhost:8000
   - Prometheus: http://localhost:9090
   - Grafana: http://localhost:3000

3. **Run Commands**
   ```bash
   docker-compose exec backend nessi
   ```
